## 9929 到底是什么，和 CN2 GIA、4837 差在哪

联通手里有几个常被拿出来说的 AS 号：**AS4837** 是常见的联通直连/普通骨干，**AS9929** 是优化骨干，业内也叫“联通 A 网”“联通优质线路”“联通精品线路”，**AS10099** 负责国际方向。商家宣传里常见的“9929+10099”，说的就是国内段走优化骨干、出国段接联通国际链路这套组合。

9929 和普通 163 骨干的实际差别不在理论峰值，而在拥塞：9929 节点少、负载轻，晚高峰不容易堵。跨省、跨域这种长距离访问时，它减少中间拥塞节点、缩短跳数，表现比 AS4837 稳，丢包更少。

和电信 CN2 GIA 的关系要说清楚：**这是两家运营商的线路，不是一回事**。CN2 GIA 是电信的高端承载，9929 是联通的优化骨干，圈内把 9929 叫“穷人版 CN2 GIA”，意思是国内方向体验接近，价格能便宜三成到一半。把这两个名字混着用，是选购时最常见的认知错误之一。

接入形态也得看懂，商家话术里的差别很大：

- 去程走 9929：你访问 VPS 的请求走优化骨干
- 回程走 9929：VPS 回国的数据走优化骨干（对国内使用体验影响最大的一环）
- 双程都优化：两个方向都尽量走 9929
- BGP 多线混合/智能路由：部分时段、部分方向走 9929，其余走备用线路

**9929 不是万能的，局限得提前知道：**

1. 9929 本身不完全自带国际出口，多数方案是“国内优化 + 接国际链路”，国际出口可能才是瓶颈；
2. 互联点、交换点少，部分省份或偏远地区接入体验不理想；
3. 你家里如果是电信或移动宽带，前端可能先走 AS4837，9929 能发挥的空间被压缩；
4. 商家控成本普遍会限制端口带宽和流量，高吞吐场景不合适；
5. 路由是动态的，宣传走 9929 不保证每时每刻都走，偶有退回 AS4837、回程丢包、延迟抖动；
6. 对电信极度依赖的业务、本地游戏服务器、极致低延迟场景，它不如 CN2 GIA 或专线。

还有一条容易被忽略：**同是 9929，上游不同表现差很多**。接的是哪段上游、机房在哪、负载控制怎么样，比“9929”这三个字重要。非高峰期 9929 和大流量便宜的 4837 差距不大，它的优势集中在晚高峰——如果你的业务主要白天跑，多花的钱意义有限。

**怎么验证商家是不是真走 9929：** 找商家要测试 IP，用 traceroute 或 LookingGlass，在晚高峰、跨省、三网分别看回程是否真落在 AS9929 上。只看商家页面上的线路名字，等于没验证。

顺便把一个更根本的区分立住：**9929 解决“快不快、稳不稳”，IP 属性解决“被不被认成本地用户”**。这两件事经常被混为一谈。原生 IP 指 IP 段归属地和机房所在地一致，在按 IP 判地域的平台眼里你是“本地人”；双 ISP 住宅 IP 再进一步，IP 在 ASN 检测中同时被识别为 ISP 类型、归属住宅宽带运营商，风控更宽松。做 TikTok、Instagram、亚马逊这类会查 IP 信誉的平台，IP 属性的权重不比线路低。

## FAQ

**9929 和 CN2 GIA 哪个好？**
不是同一个维度的比较。CN2 GIA 是电信的高端承载，9929 是联通的优化骨干。国内方向体验接近，9929 价格通常便宜三成到一半。你的用户以电信为主且预算充足，CN2 GIA 更稳；预算敏感、或者用户三网都有，9929 的性价比更高。别把两个名字混着用，这是两家的线路。

**双 ISP 住宅 IP 是不是一定不会被封？**
不是。它提升的是被识别为本地住宅用户的概率，降低的是风控触发率，不是免疫。平台风控会随 IP 段的使用情况动态调整，某个段被大量滥用后一样会被打标。买之前能测就测，别只看宣传页。

**为什么我的机器 ping 不通？**
官方已经写明：应 IP 提供方要求，部分 IP 段禁了 ping，不能 ping 属正常现象，不影响使用。用 SSH 或端口探测验证连通性即可。

**1 核 1G 能装 Windows 吗？**
官方标注这条产品线支持安装 Windows，没有按套餐区分。但 1G 内存跑 Windows 的实际体验很差，系统本身就要吃掉大半内存，剩下的一点开个浏览器就见底。真要跑 Windows，2 核 2G 的进阶版是起点。

**年付版为什么流量反而变少？**
499 元一年的特价年付版是 600GB/月，同配置的精简版月付是 1000GB/月。年付省下的 317 元，一部分就来自这 400GB 的流量差额。用量不大的人感觉不到，天天挂下载的人会。

**9929 一定比 4837 好吗？**
非高峰期差距不大，9929 的优势集中在晚高峰。你如果主要白天跑业务、对晚上八九点的丢包不敏感，便宜的 4837 方案性价比可能更高。多花的钱买的是高峰期那几小时的稳定，不需要就不必付。
